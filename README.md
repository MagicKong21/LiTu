# 荔枝图片工具箱

一个完全在浏览器本地运行的三合一图片工具：

- 图片加底：批量生成品牌底图，或在蓝图画布上自由排版最多三张图片
- 图片标注：添加序号、遮挡块和高斯模糊
- 图片编辑：删段、裁切、透明渐变、双图分隔与融合、窗口提取

所有图片只在当前浏览器标签页内处理，不会上传到服务器。导出格式统一为 PNG。

## 本地预览

在本目录启动任意静态文件服务器即可，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://127.0.0.1:8080/`。

## 部署

仓库已包含 GitHub Pages Actions 工作流。推送到 `main` 分支后，在仓库 Settings → Pages 中选择 **GitHub Actions** 作为 Source 即可发布。
